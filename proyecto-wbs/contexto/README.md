# Contexto persistente del proyecto WBS

Este directorio conserva el contexto del proyecto de entrega asociado a Jira `WBSO`.

## Alcance

Aquí se guardan notas, acuerdos, decisiones y criterios de trabajo para preparar la entrega, la demo, la defensa y la retrospectiva.

Este contexto es independiente del proyecto SDD y no debe mezclarse con `BH95` ni con los documentos de `proyecto-sdd/`.

## Archivos

- [`notas.md`](notas.md): notas crudas y contexto recibido del equipo.
- [`decisiones.md`](decisiones.md): decisiones confirmadas y pendientes explícitos.
- [`relevamiento-final.md`](relevamiento-final.md): matriz para ubicar cada pedido en la estructura de WBSO.
- [`tabla-clasificacion.md`](tabla-clasificacion.md): tabla de trabajo compartida por el usuario para revisar la clasificación y registrar su aprobación por ítem.

## Regla de uso

Antes de trabajar sobre WBSO, leer este índice y los dos archivos enlazados. Las notas pueden transformarse después en épicas, HU, tareas, bugs o criterios de aceptación, pero se conserva su origen.
