# Refinar historias

Revisar `docs/mvp.md` y el backlog disponible, si ya fue creado.

- Detectar historias demasiado amplias, ambiguas o con más de una intención.
- Mantener el actor, la acción y el beneficio visibles.
- Separar reglas de negocio de tareas técnicas.
- Señalar dependencias entre historias.
- No ampliar el alcance del MVP sin registrarlo como propuesta de cambio.

Presentar primero las modificaciones sugeridas y esperar confirmación antes de reescribir el backlog.
